# Curve Tabs — 0.1.0 preview

An **optional appearance mod by Noah Helms ([@haon-v2](https://github.com/haon-v2))** for the separately distributed [Appearance Mod Loader for Search](https://github.com/haon-v2/search-appearance-mods/releases/tag/appearance-mods-v0.1.0).

**Search was created by [Drice Roland (@driceroland)](https://github.com/driceroland) / [Office Commun](https://officecommun.com) and its contributors. Full credit for the browser belongs to them.** This mod is a community addition, not an official Search release or endorsement.

## Separate from the loader

This release contains **only the mod**: a JSON appearance manifest and documentation. It does not include the browser or loader. The loader does not bundle or automatically install this mod.

Curve Tabs configures the host’s generic top/right edge rail with an 80-point corner radius, 210-point tabs, and 12-point spacing. It inherits the host’s light/dark colors. Scroll to reach more tabs, drag to reorder, and click × to close.

## Install

1. Install the separate **Appearance Mod Loader for Search 0.1.0**.
2. Download **curve-tabs.json** below (or unzip **Curve-Tabs-v0.1.0.zip**).
3. Open **Search Mod Preview → Settings → Appearance → Import Mod…** and select the JSON file.
4. Click **Enable** beside **Curve Tabs**.

Disable or remove it in the same Settings page. Unmodified official Search, Safari, and Zen cannot load this package. Requires appearance API 1 with the `edgeRail` capability. The package executes no code and makes no network requests.

The host’s experimental rail limitations apply, including incomplete alternate-rail accessibility and no inline site card or space-switching gestures in that renderer. Those remain available in Search’s standard layout. Package license: MIT.
